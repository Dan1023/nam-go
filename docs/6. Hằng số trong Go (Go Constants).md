# Hằng số trong Go (Go Constants)

Nếu một biến cần có một giá trị cố định và không thể thay đổi, bạn có thể sử dụng từ khóa `const`.

Từ khóa `const` khai báo biến đó là một "hằng số", có nghĩa là nó **không thể thay đổi** và **chỉ đọc (read-only)**.

**Cú pháp:**

```go
const TEN_HANG_SO type = gia_tri

```

*Lưu ý: Giá trị của hằng số phải được gán ngay khi bạn khai báo nó.*

---

## Khai báo một hằng số

Dưới đây là ví dụ về cách khai báo hằng số trong Go:

**Ví dụ:**

```go
package main
import ("fmt")

const PI = 3.14

func main() {
  fmt.Println(PI)
}

```

### Quy tắc đặt tên hằng số:

* Tên hằng số tuân theo các quy tắc đặt tên giống như biến (bắt đầu bằng chữ cái hoặc dấu gạch dưới, không bắt đầu bằng số, v.v.).
* Tên hằng số thường được viết bằng **CHỮ HOA** (để dễ dàng nhận biết và phân biệt với biến).
* Hằng số có thể được khai báo cả bên trong và bên ngoài hàm.

---

## Các loại hằng số

Có hai loại hằng số:

1. **Typed constants** (Hằng số có kiểu dữ liệu xác định).
2. **Untyped constants** (Hằng số không có kiểu dữ liệu xác định).

### Hằng số có kiểu (Typed Constants)

Hằng số được khai báo với một kiểu dữ liệu cụ thể:

```go
const A int = 1

```

### Hằng số không có kiểu (Untyped Constants)

Hằng số được khai báo mà không có kiểu dữ liệu:

```go
const A = 1

```

*Lưu ý: Trong trường hợp này, kiểu dữ liệu của hằng số sẽ được suy luận từ giá trị (trình biên dịch sẽ quyết định kiểu dựa trên giá trị).*

---

## Hằng số: Không thể thay đổi và chỉ đọc

Khi một hằng số đã được khai báo, bạn không thể thay đổi giá trị của nó sau đó:

**Ví dụ (Gây lỗi):**

```go
package main
import ("fmt")

func main() {
  const A = 1
  A = 2 // LỖI: cannot assign to A
  fmt.Println(A)
}

```

---

## Khai báo nhiều hằng số

Nhiều hằng số có thể được nhóm lại trong một khối để tăng tính dễ đọc:

**Ví dụ:**

```go
package main
import ("fmt")

const (
  A int = 1
  B = 3.14
  C = "Hi!"
)

func main() {
  fmt.Println(A)
  fmt.Println(B)
  fmt.Println(C)
}

```
