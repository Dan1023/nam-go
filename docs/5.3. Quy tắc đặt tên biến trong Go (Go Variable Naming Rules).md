# Quy tắc đặt tên biến trong Go (Go Variable Naming Rules)

Một biến có thể có tên ngắn (như `x` và `y`) hoặc một tên mang tính mô tả cao hơn (`age`, `price`, `carname`, v.v.).

### Các quy tắc đặt tên biến trong Go:

* Tên biến phải bắt đầu bằng một chữ cái hoặc ký tự gạch dưới (`_`).
* Tên biến không được bắt đầu bằng một chữ số.
* Tên biến chỉ có thể chứa các ký tự chữ cái, số và dấu gạch dưới (`a-z`, `A-Z`, `0-9`, và `_`).
* Tên biến có phân biệt chữ hoa chữ thường (`age`, `Age` và `AGE` là ba biến khác nhau).
* Không có giới hạn về độ dài của tên biến.
* Tên biến không được chứa khoảng trắng.
* Tên biến không được trùng với bất kỳ **từ khóa (keywords)** nào của Go.

---

## Cách đặt tên biến có nhiều từ

Tên biến có nhiều từ có thể khó đọc nếu không được định dạng đúng. Có một số kỹ thuật bạn có thể sử dụng để làm cho chúng dễ đọc hơn:

### 1. Camel Case (Lạc đà)

Mỗi từ, ngoại trừ từ đầu tiên, đều bắt đầu bằng một chữ cái viết hoa:

```go
myVariableName = "John"

```

### 2. Pascal Case

Mỗi từ đều bắt đầu bằng một chữ cái viết hoa:

```go
MyVariableName = "John"

```

### 3. Snake Case (Con rắn)

Mỗi từ được phân tách bằng một ký tự gạch dưới:

```go
my_variable_name = "John"

```

### Lưu ý bổ sung về từ khóa (Keywords)

Bạn không thể sử dụng các từ sau làm tên biến vì chúng là các từ khóa dành riêng của ngôn ngữ Go:

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| break | default | func | interface | select |
| case | defer | go | map | struct |
| chan | else | goto | package | switch |
| const | fallthrough | if | range | type |
| continue | for | import | return | var |
