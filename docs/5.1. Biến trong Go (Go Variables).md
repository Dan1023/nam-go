# Biến trong Go (Go Variables)

Biến là các vùng chứa để lưu trữ các giá trị dữ liệu.

## Các loại biến trong Go

Trong Go, có nhiều loại biến khác nhau, ví dụ:

* `int`: lưu trữ các số nguyên (số nguyên dương hoặc âm), ví dụ: `123` hoặc `-123`.
* `float32`: lưu trữ các số thực dấu phẩy động, có phần thập phân, ví dụ: `19.99` hoặc `-19.99`.
* `string`: lưu trữ văn bản, ví dụ: "Hello World". Giá trị chuỗi được bao quanh bởi dấu ngoặc kép.
* `bool`: lưu trữ các giá trị có hai trạng thái: `true` (đúng) hoặc `false` (sai).

## Khai báo (Tạo) biến

Trong Go, có hai cách để khai báo một biến:

### 1. Sử dụng từ khóa `var`

Sử dụng từ khóa `var`, theo sau là tên biến và kiểu dữ liệu:

**Cú pháp:**

```go
var ten_bien type = gia_tri

```

*Lưu ý: Bạn luôn phải chỉ định kiểu dữ liệu (type) hoặc giá trị (value) (hoặc cả hai).*

### 2. Sử dụng toán tử `:=`

Sử dụng toán tử `:=`, theo sau là giá trị của biến:

**Cú pháp:**

```go
ten_bien := gia_tri

```

*Lưu ý: Trong trường hợp này, kiểu dữ liệu của biến sẽ được suy luận từ giá trị (nghĩa là trình biên dịch sẽ quyết định kiểu của biến dựa trên giá trị được gán).*

---

## Khai báo biến với giá trị khởi tạo

Nếu giá trị của biến đã được biết ngay từ đầu, bạn có thể khai báo và gán giá trị trên cùng một dòng:

**Ví dụ:**

```go
package main
import ("fmt")

func main() {
  var student1 string = "John" // kiểu dữ liệu là string
  var student2 = "Jane"       // kiểu dữ liệu được suy luận
  x := 2                       // kiểu dữ liệu được suy luận

  fmt.Println(student1)
  fmt.Println(student2)
  fmt.Println(x)
}

```

---

## Khai báo biến không có giá trị khởi tạo

Trong Go, tất cả các biến đều được khởi tạo mặc định. Nếu bạn khai báo một biến mà không gán giá trị ban đầu, giá trị của nó sẽ được đặt thành giá trị mặc định của kiểu dữ liệu đó:

**Ví dụ:**

```go
package main
import ("fmt")

func main() {
  var a string
  var b int
  var c bool

  fmt.Println(a) // Kết quả: "" (chuỗi rỗng)
  fmt.Println(b) // Kết quả: 0
  fmt.Println(c) // Kết quả: false
}

```

---

## Gán giá trị sau khi khai báo

Bạn có thể gán giá trị cho một biến sau khi nó đã được khai báo. Điều này hữu ích trong trường hợp giá trị chưa được xác định ngay lúc đầu.

**Ví dụ:**

```go
package main
import ("fmt")

func main() {
  var student1 string
  student1 = "John"
  fmt.Println(student1)
}

```

*Lưu ý: Bạn không thể khai báo một biến bằng `:=` mà không gán giá trị cho nó ngay lập tức.*

---

## Sự khác biệt giữa `var` và `:=`

Có một số khác biệt nhỏ giữa việc sử dụng `var` và `:=`:

| Đặc điểm | `var` | `:=` |
| --- | --- | --- |
| **Phạm vi** | Có thể sử dụng bên trong và bên ngoài hàm. | Chỉ có thể sử dụng bên trong hàm. |
| **Khai báo & Gán** | Khai báo và gán giá trị có thể thực hiện riêng biệt. | Khai báo và gán giá trị phải thực hiện cùng lúc (trên cùng một dòng). |

### Ví dụ về `var` bên ngoài hàm:

```go
package main
import ("fmt")

var a int
var b int = 2
var c = 3

func main() {
  a = 1
  fmt.Println(a)
  fmt.Println(b)
  fmt.Println(c)
}

```

### Ví dụ lỗi khi dùng `:=` bên ngoài hàm:

```go
package main
import ("fmt")

a := 1 // LỖI: syntax error: non-declaration statement outside function body

func main() {
  fmt.Println(a)
}

```
