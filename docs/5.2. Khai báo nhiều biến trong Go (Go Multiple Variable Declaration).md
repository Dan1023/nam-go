# Khai báo nhiều biến trong Go (Go Multiple Variable Declaration)

Trong Go, bạn có thể khai báo nhiều biến trên cùng một dòng.

## Khai báo trên cùng một dòng

Ví dụ sau đây cho thấy cách khai báo nhiều biến trên cùng một dòng:

**Ví dụ:**

```go
package main
import ("fmt")

func main() {
  var a, b, c, d int = 1, 3, 5, 7

  fmt.Println(a)
  fmt.Println(b)
  fmt.Println(c)
  fmt.Println(d)
}

```

*Lưu ý: Nếu bạn sử dụng từ khóa kiểu dữ liệu (như `int`, `string`), bạn chỉ có thể khai báo các biến có cùng kiểu dữ liệu đó trên một dòng.*

Nếu không chỉ định kiểu dữ liệu, bạn có thể khai báo các biến với các kiểu dữ liệu khác nhau trên cùng một dòng:

**Ví dụ:**

```go
package main
import ("fmt")

func main() {
  var a, b = 6, "Hello"
  c, d := 7, "World!"

  fmt.Println(a)
  fmt.Println(b)
  fmt.Println(c)
  fmt.Println(d)
}

```

---

## Khai báo biến trong một khối (Block)

Bạn cũng có thể nhóm các khai báo biến lại với nhau trong một khối để tăng tính dễ đọc cho mã nguồn:

**Ví dụ:**

```go
package main
import ("fmt")

func main() {
   var (
     a int
     b int = 1
     c string = "hello"
   )

  fmt.Println(a)
  fmt.Println(b)
  fmt.Println(c)
}

```

---

### Tóm tắt các điểm cần nhớ:

1. **Cùng kiểu dữ liệu:** Có thể dùng `var a, b int = 1, 2`.
2. **Khác kiểu dữ liệu:** Có thể dùng `var a, b = 1, "hi"` hoặc `a, b := 1, "hi"`.
3. **Dùng khối `var ()`:** Giúp gom nhóm các biến có liên quan hoặc khai báo nhiều biến ở đầu hàm/file một cách gọn gàng.
